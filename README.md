# freecad-flake

A Nix Flake providing a custom, declarative FreeCAD wrapper module and packaging system with dynamic plugin discovery and XML configuration injection.

## Features

* **Dynamic Plugin Discovery**: Automatically imports and builds workbench plugins located in `./plugins/*.nix` (e.g., `sheet-metal`, `fasteners`, `history`), generating boolean toggle options programmatically via `lib.genAttrs`.

* **XML Configuration Ingestion**: Inject custom baseline `user.cfg` and global `system.cfg` XML files directly through the launcher wrapper.

* **Custom FreeCAD Wrapper**: Utilizes `pkgs.freecad.customize` to produce a customized FreeCAD derivation (`programs.freecad.package`).

* **Flake Native**: Seamless integration with NixOS system configurations and Home Manager environments.

## Installation

Add `freecad-flake` to your `flake.nix` inputs:

```
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    freecad-flake.url = "github:chrisppy/freecad-flake";
  };

  outputs = { self, nixpkgs, freecad-flake, ... }@inputs: {
    # Your flake outputs...
  };
}

```

## Module Usage

Import the module directly into your NixOS system configuration:

```
{ inputs, pkgs, ... }: {
  imports = [
    inputs.freecad-flake.nixosModules.default
  ];

  programs.freecad = {
    enable = true;

    # Dynamically toggled workbench plugins discovered from ../plugins/*.nix
    plugins = {
      fasteners = true;
      sheet-metal = true;
      history = true;
    };

    # XML configuration templates
    userCfg = ./config/user.cfg;
    systemCfg = ./config/system.cfg;

    # Custom wrapper flags or extra python extension package mappings
    makeWrapperFlags = [
      "--set QT_QPA_PLATFORM wayland"
    ];
  };
}

```

## Configuration Options

| Option | Type | Default | Description | 
| ----- | ----- | ----- | ----- | 
| `programs.freecad.enable` | boolean | `false` | Enable customized FreeCAD installation wrapper. | 
| `programs.freecad.plugins.<name>` | boolean | `false` | Enable custom upstream plugin workbench (dynamically generated for each `.nix` file in `plugins/`). | 
| `programs.freecad.userCfg` | null or path | `null` | Path to a baseline `user.cfg` XML template file injected via launcher wrapper. | 
| `programs.freecad.systemCfg` | null or path | `null` | Path to a global `system.cfg` XML template file injected via launcher wrapper. | 
| `programs.freecad.pythons` | list of unspecified | `null` | Python extensions package mappings passed directly to `pkgs.freecad.customize`. | 
| `programs.freecad.makeWrapperFlags` | list of strings | `null` | Flags passed directly to `makeWrapper` inside the customization derivation. | 
| `programs.freecad.package` | package | *(read-only)* | The resulting customized FreeCAD package derivation generated by `pkgs.freecad.customize`. |
